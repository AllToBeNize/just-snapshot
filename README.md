# Snapshot

轻量的 Windows 截图工具，Rust + 原生 Win32 实现，常驻托盘时几乎不占资源。支持 Windows 10 / 11 x64。

- **智能选区**：自动吸附窗口、界面控件和内容区，也可以自由拖框，带像素尺寸和 5 倍放大镜
- **标注**：矩形、文本、画笔、马赛克，支持撤回 / 重做
- **长截图**：边滚动边拼接，实时预览
- **贴图**：把截图钉在屏幕最前面，可拖动、缩放、调透明度
- **可自定义**：全局截图键和工具栏快捷键都能改，四套配色（默认深色），默认开机自动启动

## 下载安装

到 [Releases](https://github.com/AllToBeNize/snapshot/releases) 下载最新的 `snapshot-v<版本>-windows-x64.zip`，解压后运行 `snapshot.exe`，程序会驻留在系统托盘。

第一次运行时 Snapshot 会把自己加入开机启动。不需要的话，右键托盘图标 →「设置」，取消勾选「登录 Windows 时自动启动」。

## 快速上手

1. 按 **`Ctrl+Alt+A`** 开始截图。移动鼠标会自动预选窗口、控件或内容区，单击锁定；也可以按住左键拖出自由选区。
2. 选好后，工具栏**居中**出现在选区正下方。下方空间不够时放到选区上方，全屏选区时放在选区内部底部。
3. 选中画笔、文本、马赛克时，二级参数栏（粗细、字号、颜色）**居中挂在工具栏下方**。
4. 按 `Enter` / `Ctrl+C` 或双击选区复制，`Ctrl+S` 保存 PNG，`Esc` 退出。

选区锁定后仍可调整：拖动内部移动，拖边线或四角缩放。右键清除选区回到自动预选，再右键退出。

## 工具栏

工具栏从左到右分三组：

| 分组 | 按钮 | 默认快捷键 |
| --- | --- | --- |
| 绘图 | 矩形 · 文本 · 画笔 · 马赛克 | `Ctrl+1` · `Ctrl+2` · `Ctrl+3` · `Ctrl+4` |
| 历史 | 撤回 · 重做 | `Ctrl+5` / `Ctrl+Z` · `Ctrl+6` / `Ctrl+Y` / `Ctrl+Shift+Z` |
| 输出 | 长截图 · 贴图 · 保存 · 退出 · 复制 | `Ctrl+7` · `Ctrl+T` · `Ctrl+S` · `Esc` · `Ctrl+C` |

再次点当前工具或按右键可以退出标注。撤回和重做每次处理一笔，或一次文本编辑、样式修改、变换。

- **画笔**：左键自由绘制，参数栏调粗细和颜色，滚轮也能快速调粗细。
- **马赛克**：跟着圆形光标涂抹，参数栏分别调笔刷直径和像素块大小。
- **文本**：单击或拖出文本框，参数栏调字号和颜色。拖边缘移动，拖四角缩放，拖上方手柄旋转。`Ctrl+Enter` 确认，`Esc` 退出输入；单击已有文本框选中，双击编辑。

## 长截图

适合网页正文、聊天记录和长文档。框住会滚动的内容（给旁边的预览面板留点空间），点「长截图」或按 `Ctrl+7`。蓝框固定后，在框内滚动鼠标滚轮操作原窗口，旁边实时预览拼好的长图。复制、保存的快捷键和普通截图一样，右键或 `Esc` 回到原选框。

滚得太快导致预览停住时，往回滚一点，让前后两屏重新有重叠就能接上。

## 贴图

点「贴图」或按 `Ctrl+T`，截图会钉在屏幕最前面：左键拖动，滚轮缩放，`Ctrl+滚轮` 调透明度（最低 15%），右键或双击关闭。

## 设置

右键托盘图标 →「设置」：

- **快捷键**：点一下按键区域，再按下新的组合键（`Esc` 取消）。全局截图键和工具栏快捷键都能改。
- **贴图透明度步长**：每格滚轮改变的百分点，1 到 100，默认 5；按住 Shift 点 −/+ 一次调 10。
- **开机启动**：登录 Windows 时自动启动，首次运行默认开启。
- **外观**：石墨（默认深色）、午夜蓝、墨绿、浅色四套配色，截图工具栏、设置窗口和提示框一起换，选中即可预览。

保存后立即生效，也可以恢复默认。配置保存在 `%LOCALAPPDATA%\Snapshot\shortcuts.txt`。

截图键被其他程序占用时，托盘图标右下角会出现橙色感叹号并弹出一次通知，程序照常驻留：双击托盘图标仍可截图，点通知或托盘菜单就能去设置里换一个。设置窗口里改快捷键时会当场检测是否被占用，重复的按键会标出来。

## 从源码构建

在 Windows 上安装 [Rust MSVC 工具链](https://rustup.rs/) 和 Visual Studio C++ 生成工具（含 Windows SDK），然后运行 `.\snapshot.ps1 build`。
