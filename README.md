# Snapshot

轻量的 Windows 截图工具，Rust + 原生 Win32 实现，常驻托盘时几乎不占资源。支持 Windows 10 / 11 x64。

- **智能选区**：自动吸附窗口、界面控件和内容区，鼠标侧键（或滚轮）逐层切换控件 / 面板 / 窗口 / 整屏，也可以自由拖框，带像素尺寸和 5 倍放大镜，按 `C` 复制鼠标下的颜色；可以直接输入宽高，方向键微调；全局快捷键一键截取当前窗口
- **标注**：矩形（圆角 / 虚线）、文本（水平 / 垂直对齐、描边、底色、拖边改宽高）、画笔、马赛克、箭头、序号、局部放大镜，选择工具可以框选多个标注一起移动；画好的标注可以重新选中、移动、调整、改样式或删除，支持撤回 / 重做
- **找回上次截图**：截完或误按了 `Esc`，一个快捷键回到上一次的画面、选区和标注
- **长截图**：边滚动边拼接，实时预览
- **贴图**：把截图钉在屏幕最前面，可拖动、缩放、调透明度，右键菜单可以取消置顶、分组显示 / 隐藏
- **保存**：保存位置和文件名模板可设置，可以每次截图自动存一份，保存时可加阴影和边框
- **提取文字**：截图里的文字和二维码 / 条形码识别出来，直接在贴图上拖选复制，离线完成，不用联网
- **复制即文件**：复制的截图在资源管理器或桌面里 `Ctrl+V` 就是一个 PNG 文件，聊天软件里粘贴照样是图片
- **翻译**：识别出的文字一键翻译，译文在贴图旁的小窗里；开箱即用免费翻译，不用密钥，也可以接 OpenAI 兼容接口、DeepL、百度或有道，密钥只存在 Windows 凭据管理器里
- **可自定义**：全局截图键和工具栏快捷键都能改，四套配色（默认深色），默认开机自动启动

## 下载安装

到 [Releases](https://github.com/AllToBeNize/snapshot/releases) 下载最新的 `snapshot-v<版本>-windows-x64.zip`，解压后运行 `snapshot.exe`，程序会驻留在系统托盘。

第一次运行时 Snapshot 会把自己加入开机启动。不需要的话，右键托盘图标 →「设置」，取消勾选「登录 Windows 时自动启动」。

## 快速上手

1. 按 **`Ctrl+Alt+A`** 开始截图。移动鼠标会自动预选窗口、控件或内容区，按鼠标侧键「后退」扩大到外面一层、「前进」缩回里面一层（滚轮上下、`Alt+←/→` 也一样，尺寸标签上显示「层 2/5」），一移动鼠标就恢复自动预选；单击锁定；也可以按住左键拖出自由选区，或按 `Ctrl+A` 直接选中鼠标所在的整个屏幕。
2. 选好后，工具栏**居中**出现在选区正下方。下方空间不够时放到选区上方，全屏选区时放在选区内部底部。
3. 选中画笔、文本、马赛克、箭头、序号时，二级参数栏（粗细、字号、大小、颜色）**居中挂在工具栏下方**。
4. 按 `Enter` / `Ctrl+C` 或双击选区复制，`Ctrl+S` 保存 PNG，`Esc` 退出。复制的截图在资源管理器里直接 `Ctrl+V` 会存成 `Snapshot 日期 时间.png`。

拖选区或调整选区时，放大镜下方显示鼠标所指像素的颜色，按 `C` 复制 `#RRGGBB`。

选区锁定后仍可调整：拖动内部移动，拖边线或四角缩放。右键清除选区回到自动预选，再右键退出。

- **输入宽高**：单击选区左上方的尺寸标签，直接输入 `800 600`、`800x600` 之类，回车生效，`Esc` 取消。
- **方向键**：移动选区 1 像素，`Shift` 一次 10 像素；`Ctrl+方向键` 从右下角改大小。选中了标注时，方向键移动的是标注。
- **截取当前窗口**（`Ctrl+Alt+W`，全局）：直接选中当前活动窗口（不含透明阴影边），工具栏立即出现。
- **找回上次截图**（`Ctrl+Alt+R`，全局，托盘菜单里也有）：回到上一次截图时冻结的画面，选区、标注和撤回记录都还在。只保留最近一次，存在内存里，退出程序或屏幕排列变了就不能找回。

## 工具栏

工具栏从左到右分四组：

| 分组 | 按钮 | 默认快捷键 |
| --- | --- | --- |
| 绘图 | 矩形 · 文本 · 画笔 · 马赛克 · 箭头 · 序号 · 放大镜 · 选择 | `Ctrl+1` ～ `Ctrl+8`，按工具栏顺序 |
| 历史 | 撤回 · 重做 | `Ctrl+Z` · `Ctrl+Y` / `Ctrl+Shift+Z` |
| 文字 | 提取文本 · 翻译 | `Ctrl+E` · `Ctrl+F` |
| 输出 | 长截图 · 贴图 · 保存 · 退出 · 复制 | `Ctrl+L` · `Ctrl+T` · `Ctrl+S` · `Esc` · `Ctrl+C` / `Enter` |

撤回、重做是分界线：前面的绘图工具从 `Ctrl+1` 起按顺序编号，从撤回开始每个按钮用自己好记的快捷键。鼠标停在按钮上会显示名称和快捷键；左下角的提示面板分「选区 / 当前工具」「标注」「输出」几栏，列出当前界面能用的全部快捷键。以前版本保存过的默认快捷键会自动换成新的布局，自己改过的保持不变。

再次点当前工具或按右键可以退出标注。撤回和重做每次处理一笔，或一次文本编辑、样式修改、变换，选区的移动和缩放也能撤回。

- **矩形**：拖出方框，参数栏调粗细、颜色，「圆角」「虚线」可以单独打开。
- **画笔**：左键自由绘制，参数栏调粗细和颜色，滚轮也能快速调粗细。
- **马赛克**：跟着圆形光标涂抹，参数栏分别调笔刷直径和像素块大小。
- **箭头**：从起点拖到要指的位置，参数栏调粗细和颜色。
- **序号**：每单击一次放下一个带数字的圆点，数字自动递增（撤回后接着用空出来的号），按住拖动可以先挪好位置再松开；参数栏调大小和颜色。
- **放大镜**：在要放大的地方按下，向外拖出圆的大小（单击是默认大小），松开后旁边出现一个放大的圆形镜头，用两条切线连到原处；参数栏调倍数（2–6 倍）和边框颜色。镜头会自动放在右上方，放不下时换到其他角。
- **文本**：单击或拖出文本框，参数栏调字号、颜色、水平对齐（居左 / 居中 / 居右）和垂直对齐（靠上 / 居中 / 靠下），「描边」给文字加一圈双色描边（深浅背景上都看得清，输入时也能看到），「底色」给文本框铺一块圆角色块。选中后拖四边中点的控制点像 Office 文本框一样改宽高（字号不变，文字重新换行），拖四角连字号一起缩放。
- **选择**：单击标注选中，按住 `Ctrl` 单击加选或取消，在空白处拖出方框框选；拖动任意一个选中的标注，所有选中的一起移动，方向键也一起移动，`Delete` 一起删除，每一步都能一次撤回。拖边缘移动，拖四角缩放，拖上方手柄旋转。`Ctrl+Enter` 确认，`Esc` 退出输入；单击已有文本框选中，双击编辑。

**重新编辑画好的标注**：没有选工具时单击任意标注（矩形点边线），或在同一种工具下单击同类标注，就会选中它并显示控制点：拖动移动，拖控制点调整（矩形的八个点、箭头的两端、序号和放大镜的大小），参数栏改的样式直接作用到它，`Delete` 删除，右键或 `Esc` 取消选中。放大镜拖镜头只移动镜头，拖小圆则连同镜头一起移动并重新取景。这些修改都能撤回。

## 长截图

适合网页正文、聊天记录和长文档。框住会滚动的内容（给旁边的预览面板留点空间），点「长截图」或按 `Ctrl+L`。蓝框固定后，在框内滚动鼠标滚轮操作原窗口，旁边实时预览拼好的长图。复制、保存的快捷键和普通截图一样，右键或 `Esc` 回到原选框。

滚得太快导致预览停住时，往回滚一点，让前后两屏重新有重叠就能接上。

## 提取文字

选好区域后点「提取文本」或按 `Ctrl+E`，截图会变成贴图，并在后台用 Windows 自带的文字识别读出里面的文字，左下角提示识别到几行。识别完成后：

- 鼠标移到贴图上，能选的文字会浅浅地标出来；在文字上按住左键拖动就能选中，跨行也可以，双击选中一整行，`Ctrl+A` 全选。
- `Ctrl+C` 复制选中的文字，没选时复制全部；右上角的「复制全部文字」按钮也可以。
- 截图里的**二维码和条形码**也会一起识别出来并用蓝框标出。鼠标移上去能看到内容，单击复制；是网址时按住 `Ctrl` 单击直接在浏览器打开。
- 文字和码以外的地方照常拖动贴图；`Esc` 先取消选择，再按一次关闭贴图。

识别完全离线，支持的语言跟着 Windows 已安装的语言走（中文系统默认有简体中文和英文）。屏幕上 16 像素以上的文字基本都能认对，更小的字会先放大再识别，个别字符可能认错。

## 翻译

选好区域后点「翻译」或按 `Ctrl+F`，截图变成贴图，先识别文字再翻译。译好后**译文直接盖在贴图的原文上**：每一行用原来的底色盖住，按原来的文字颜色写上译文，字号自动缩到放得下（译文行数和原文对不上时，整块文字区域改成一段自动换行的译文）。贴图左上角的「显示原文 / 显示译文」按钮随时切换；看原文时文字能像「提取文字」一样拖选复制。

贴图旁边还有一个译文小窗，显示进度、完整译文和出错原因：默认在贴图右边，右边放不下就到左边，拖动贴图时跟着走，关掉贴图一起关。

- **目标语言**：小窗左上角的按钮，默认「自动」——中文译成英文，其他语言译成中文；点开可以指定中文、英文、日语、韩语、法语、德语、西班牙语或俄语，切换后马上重译。
- **复制**：「复制译文」按钮；没有选中原文时 `Ctrl+C` 也复制译文。译文长了可以在小窗里滚动。
- **出错时**：小窗里完整显示原因（例如密钥不对、额度用完、网络不通），可以「重试」或打开「翻译设置」。网络出错、限流和服务器错误会自动重试两次。

### 配置翻译服务

默认用**免费翻译**，不用注册也不用密钥。想换服务时，点设置窗口「翻译」那一行的齿轮，或译文小窗右上角的齿轮。

| 服务商 | 需要填 | 说明 |
| --- | --- | --- |
| 免费翻译 | 不用填（邮箱可选） | 用 [MyMemory](https://mymemory.translated.net/doc/spec.php) 的公共接口，自动识别原文语言。不填邮箱每天约 5000 字，填写邮箱提高到约 5 万字；长文按约 150 字一段、每段间隔 1 秒发送。质量一般，正式使用建议换下面的服务 |
| OpenAI 兼容 | 接口地址、模型、API Key | OpenAI、DeepSeek、通义千问、Kimi、Ollama 等支持 `/chat/completions` 的接口都能用；本地模型可以不填 Key |
| DeepL | API Key | 免费版密钥以 `:fx` 结尾，会自动走免费接口 |
| 百度翻译 | APP ID、密钥 | 百度翻译开放平台的「通用文本翻译」 |
| 有道翻译 | 应用 ID、应用密钥 | 有道智云的「文本翻译」应用 |

填好后可以先点「测试连接」翻译一句试试。**密钥只保存在本机的 Windows 凭据管理器里**（控制面板 › 凭据管理器 › Windows 凭据，名称以 `Snapshot/translate/` 开头），不会写进任何文件；保存后窗口里只显示「已保存」，留空表示沿用。其余设置在 `%LOCALAPPDATA%\Snapshot\translate.txt`。

## 贴图

点「贴图」或按 `Ctrl+T`，截图会钉在屏幕最前面：左键拖动，滚轮缩放，`Ctrl+滚轮` 调透明度（最低 15%），`Ctrl+C` 复制图片，`Esc` 或双击关闭。

右键打开菜单：复制图片、保存、**置顶**（取消后其他窗口可以盖住它）、**分组**、隐藏本组、关闭。新贴图放进最近选过的组；托盘菜单的「贴图」里可以显示 / 隐藏全部贴图、按组勾选显示，或者关闭所有贴图。

## 设置

右键托盘图标 →「设置」：

- **快捷键**：点一下按键区域，再按下新的组合键（`Esc` 取消）。设置窗口开着时也可以截图（比如截设置界面反馈问题），只有正在录入快捷键时截图键不响应。全局截图键和工具栏快捷键都能改；截图还可以再设一个**副键位**，两个同时生效。
- **贴图透明度步长**：每格滚轮改变的百分点，1 到 100，默认 5；按住 Shift 点 −/+ 一次调 10。
- **开机启动**：登录 Windows 时自动启动，首次运行默认开启。
- **外观**：石墨（默认深色）、午夜蓝、墨绿、浅色四套配色，截图工具栏、设置窗口和提示框一起换，选中即可预览。
- **保存截图**：点「设置…」打开保存设置——保存位置（默认「图片\Snapshot」）、文件名模板（可用 `{date}` `{time}` `{w}` `{h}`，默认 `Snapshot {date} {time}`）、**自动保存**（打开后每次复制、贴图或保存都在这个位置存一份，「保存」也不再弹对话框）、**阴影**（四周加柔和投影，透明背景 PNG）和**边框**（一像素深色细边）。阴影和边框只加在保存的文件上，复制到剪贴板的还是原图。保存在 `%LOCALAPPDATA%\Snapshot\output.txt`。

保存后立即生效，也可以恢复默认。配置保存在 `%LOCALAPPDATA%\Snapshot\shortcuts.txt`。

截图键被其他程序占用时，托盘图标右下角会出现橙色感叹号并弹出一次通知，程序照常驻留：双击托盘图标仍可截图，点通知或托盘菜单就能去设置里换一个。设置窗口里改快捷键时会当场检测是否被占用，重复的按键会标出来。

## 从源码构建

在 Windows 上安装 [Rust MSVC 工具链](https://rustup.rs/) 和 Visual Studio C++ 生成工具（含 Windows SDK），然后运行 `.\snapshot.ps1 build`。
